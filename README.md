## About Me

I am a **DevOps Engineer** focused on building reliable, scalable, and automated infrastructure. My primary interest lies in bridging the gap between software development and IT operations through **automation, cloud computing, containerization, infrastructure as code, and continuous delivery practices**.

I work with technologies such as **AWS, Docker, Kubernetes, Terraform, Ansible, Linux, Bash, Git, GitHub, Nginx, and Apache** to build and manage modern infrastructure environments.

My goal is to become a strong **Cloud and DevOps Engineer** capable of designing, automating, deploying, monitoring, and maintaining production-grade systems.

### Engineering Focus

- Designing and deploying cloud infrastructure on AWS
- Containerizing applications using Docker
- Managing containerized workloads with Kubernetes
- Automating infrastructure using Terraform
- Configuring systems using Ansible
- Working with Linux and Bash automation
- Managing web servers using Nginx and Apache
- Version controlling infrastructure and application code using Git and GitHub
- Building reliable, repeatable, and automated deployment workflows

### Open To

- DevOps Engineering Opportunities
- Cloud Engineering Roles
- Infrastructure Automation Projects
- Platform Engineering
- Open Source Collaboration
- Entry-Level and Fresher DevOps Opportunities
